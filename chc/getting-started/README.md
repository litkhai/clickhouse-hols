## English

This walkthrough moved to the notes site and was rewritten there: **[Getting started with ClickHouse Cloud: from sign-up to every console menu](https://clickhouse.litkhai.dev/en/articles/cloud/clickhouse-cloud-getting-started/)**.

The article was checked against the live console on 2026-11-07 (ClickHouse 26.8, AWS Seoul) and covers:

- creating a service (size presets, vertical or horizontal autoscaling, compute-compute separation, TDE)
- SQL console, Data sources, Dashboards and Connect
- the ten Monitoring screens and which one answers which question
- Backups, service Settings (scaling, idling, release channels, IP access list, JWT, Query API)
- the Organization menus (billing, users and roles, API keys, audit, notifications, preview features) and a first-week checklist

The earlier text here was a copy of a 2024 post that stopped at sign-up, one table and a SQL client. It is in the git history of this directory.
